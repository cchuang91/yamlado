## 📦 現已交付功能 (Delivered Features)

### 1. 品牌首頁與主視覺
- **頂部導覽列 (Navbar)**：支援手機版漢堡選單展開/關閉、純鍵盤操作、預購清單即時數量徽章。
- **限時活動橫幅 (Promo Countdown)**：支援固定時區（`+08:00`）倒數、優惠碼一鍵複製與 Toast 操作反饋、過期狀態優雅切換。
- **首屏主視覺 (Hero Section)**：強力呼應「寵愛你的毛小孩」，結合樂園綠與暖陽橙雙色標題。
- **品牌故事 (Brand Story)**：融入多多與樂樂的快樂生活理念。

### 2. 商品型錄與即時互動
- **分類篩選與即時搜尋**：多分類與關鍵字搜尋可同時協同運作，支援查無結果友善重設。
- **商品快速預覽彈窗 (Modal)**：嚴格使用 `textContent` 安全填入，支援 `Esc` 與遮罩點擊關閉。
- **預購清單 (Pre-order Cart)**：
  - 增減數量、刪除品項、動態計算原價小計與活動 88 折優惠。
  - 使用 `localStorage` 本地儲存，重新整理資料不遺失。
  - 提供聯絡人暱稱（防呆驗證）與備註需求。
  - **複製預購明細**（排版工整，可直接貼至 LINE/IG 私訊）與 **下載純文字單 (.txt)**。

### 3. 動態顧客評價與常見問答
- 顧客好評卡片動態自 `js/data.js` 載入。
- FAQ 常見問題手風琴支援純鍵盤 `Tab`、`Enter`、`Space` 展開與折疊。
